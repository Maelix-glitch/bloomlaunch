1920×1080, WebP, 24 fps. Exported from the production scene `BloomCinematicHero`;
copied here verbatim for the launch site. **Do not regenerate or alter these files.**

- `frames.json` — original manifest from the export.
- `manifest.json` — extended manifest (`start`, `count`) consumed by `src/hero/frames.ts`.
